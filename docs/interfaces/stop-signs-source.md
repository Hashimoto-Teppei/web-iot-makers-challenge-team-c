# 外部データ（一時停止の標識）

**一時停止の標識をどこから取ってきて、何を取り込み、何を捨てたか。**

[`web-service.md`](./web-service.md) から分割した（2026-09-02。あちらが 400 行を超えたため。
`CLAUDE.md`「ドキュメントを書くとき」）。**素性の話は、集計・取り込み・テーブルとは読む人が違う**
——標識の取り込み（`apps/web/scripts/stop-signs/`）とモバイルの一時停止の事前通知（#27）が読む。

**JARTIC の交通規制情報オープンデータから抽出する。**
一旦停止は**共通規制種別コード `63`**、岡山県は**都道府県コード `33`**。経緯度が含まれる。
**実データで確認済み**（2026-09-01。岡山県 202607 の原本から 28,651 件。
岡山駅から半径 1km に 471 件、5km に 5,192 件あり、市街地の密度は足りている）。

- **リポジトリに置くのは抽出スクリプトだけ。** CSV も、生成した SQL も置かない。
  このリポジトリは public であり、**配布に当たる置き方をしない**（`CLAUDE.md`）
- **`.gitignore` に入れて、記憶ではなく仕組みで止める。**
  ダウンロード先のディレクトリと、生成物の拡張子の両方を書く。
  **ディレクトリごとではなく中身を無視する**（`data/*` と README の除外）——
  丸ごと無視すると、**「ここに置く」と書いた説明そのものが追跡できなくなる**
- **抽出した結果は D1 に入れる。** D1 は公開の場ではない
- **原本の置き場所は `apps/web/scripts/stop-signs/data/`。**
  データは月次で更新され、**前月ぶんは取得できない**ため、
  **その PC が失われた時点で作り直せなくなる。**
  **それでもリポジトリ外へのバックアップは取らない**（決定済み・2026-09-01）——
  原本を触るのは1人だけで、**取り込んだ結果は D1 にあり PC の外にある。**
  失って困るのは D1 に入れなかった列と、別の月との突き合わせに限られる。
  **期間が延びる・触る人が増えるなら決め直す。**
  **置き場所の運用（コミットさせない仕組み、いま何が置いてあるか）は
  [`data/README.md`](../../apps/web/scripts/stop-signs/data/README.md)。**
  **判断そのものはここが正本**なので、決め直すときはこの節を直す
- **抽出スクリプトの置き場所は `apps/web/scripts/stop-signs/`。**
  標識の正本は D1 で、その面倒を見るのは Web/API の担当だから。
  **`packages/` は作らない**——モバイルが受け取るのは**コードではなく `signs.db` という成果物**で、
  `CLAUDE.md` が言う「2つ目の利用者」に当たらない（`../adr/0009-on-device-storage.md`）
- **版（`ETag` の元になる値）を D1 に持つ。** 抽出のたびに更新する。
  **端末はこの値をそのまま持ち帰る**ので、**ここで作らないと端末が独自の版を作り始める**
- **「規制場所の経度緯度」だけでなく「進入方向（座標）」も取り込む。**
  一時停止は**点規制(2)**——規制地点と、**その規制が対象とする車両の進入方向**が
  組で登録されている（拡張版標準フォーマット説明書 3.5.2）。
  **捨てると、一時停止の事前通知が対向車線と交差する道路の標識で鳴る。**
  配り方は [`mobile-api.md`](./mobile-api.md)「進入方向を一緒に配る」
- **交差点名称は取り込まない**（決定済み・2026-09-01）。当初は「走行後の画面で場所が人に読める」
  ようにするため D1 に残す方針だったが、**原本（岡山県警 202607）の 65,373 行すべてで空**だった
  ——一時停止に限らず、全規制種別で空である。**入らない列のために書き込みと列を持ち続けない**ので、
  列ごと落とした（マイグレーション `0002`）。
  **読める場所は出さないと決めた**（2026-09-01。[`web-ui.md`](./web-ui.md)
  「場所は地図が示す。名前をデータベースに持たない」）。**逆ジオコーディングもしない。**
  **他県が入れている可能性は残る**（県を選べるようにするのは #71）。
  そのときは列と抽出を戻す——`scripts/stop-signs/csv.ts` の `COLUMN` に足す1行から始まる。
  **月次更新で前月ぶんは取得できない**ので、**戻すと決めた月から先のぶんしか集まらない**
- **取り込みで捨てた列は取り戻せない**（上と同じ理由）。**中身を見ずに捨てない**——
  交差点名称を落としたのは、**実データが空だと確かめたから**であって、要らなそうだからではない

**D1 に入れたものをスマホの手元へ配るところは
[`mobile-api.md`](./mobile-api.md)「一時停止の標識をスマホに配る」、
端末側の置き方は [`../adr/0009-on-device-storage.md`](../adr/0009-on-device-storage.md) が正本**（#63）。
**このファイルの範囲は D1 に入れるところまで。**

**`GET /api/stop-signs` は開発時にも使う。** 各自のアプリに同梱する `signs.db` は
**この経路から作る**（JARTIC の原本を全員が扱わずに済ませるため。`../adr/0009-on-device-storage.md`）。
**この API を壊すと、走行中だけでなくアプリのビルドも止まる。**
