## GPS の性能（NEO-6M）

**この値が検知アルゴリズムの前提になる。** データシート上の値であり、実機では確かめていない
（`unverified.md`）。

| 項目 | 値 | 効いてくるところ |
| --- | --- | --- |
| 測位の更新頻度 | **既定 1Hz / 最大 5Hz** | 1Hz だと時速 20km で**1秒あたり約 5.5m 進む**。急接近の検知には粗い |
| 水平位置精度 | 2.5m | 標識の検知（#27）で、隣の道路の標識と区別できるかに直結する |
| 起動から測位まで | コールド 27秒 / ホット 1秒 | **デモで電源を入れ直すと 27秒待たされる**。基板上の電池が生きていればホットになる |
| 出力 | NMEA / UBX / RTCM | 既定は NMEA。更新頻度を上げるには UBX でコマンドを送る |
| ボーレート | 既定 9600（4800〜230400） | 5Hz に上げるなら 9600 では足りなくなる可能性がある |
